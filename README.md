# Image Processing - Lab 2

## Digital Image Fundamentals

This lab covers fundamental concepts and operations in digital image processing using Python.

### Topics Covered
- Image Sampling
- Image Quantization
- Image Arithmetic Operations
  - Image Addition
  - Image Subtraction
  - Addition with a Constant
- Set / Logical Operations
  - Union
  - Intersection
  - Set Difference
  - Symmetric Difference

### Tools and Libraries
- Python
- OpenCV
- NumPy
- Matplotlib
- PIL
- scikit-image
